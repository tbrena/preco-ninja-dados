# Preço Ninja — dados

`ofertas.json`: ofertas do Mercado Livre selecionadas pelo bot do
[ofertaninja.online](https://ofertaninja.online), atualizado automaticamente a cada
rodada (GitHub Actions do repositório do site). O site lê este arquivo direto daqui.

Só desconto real: preço comparado com a mediana dos outros vendedores do mesmo produto.
